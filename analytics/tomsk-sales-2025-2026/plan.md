# План анализа продаж Томск 2025-2026

## Задача
Проанализировать продажи салонов в Томске за 2025-2026 годы:
1. Выявить каналы с наибольшим снижением продаж
2. Определить товары с наибольшим снижением продаж
3. Подготовить текстовый отчёт с цифрами и выводами

## Исходные данные
- Файл: `Заказы Томск 25-26.xlsx`
- Заказов: 17 954
- Период: 2025-2026 (точный диапазон дат нужно уточнить)
- Каналы: столбец "Способ оформления"
- Товары: столбец "Состав"

## План действий

### Фаза 1. Подготовка данных
- [ ] Загрузить данные из Excel в Python
- [ ] Проверить пропуски, дубликаты, аномалии
- [ ] Определить точный временной диапазон данных (начало и конец)
- [ ] Выяснить уникальные каналы продаж ("Способ оформления")
- [ ] Определить, какие статусы заказов учитывать для анализа продаж

### Фаза 2. Парсинг товаров
- [ ] Изучить формат столбца "Состав"
- [ ] Написать функцию для извлечения отдельных товаров из "Состав"
- [ ] Создать таблицу товаров: заказ_id, товар, количество, цена
- [ ] Определить топ-N товаров для анализа

### Фаза 3. Анализ по каналам
- [ ] Сгруппировать продажи по каналам и по месяцам
- [ ] Рассчитать динамику: помесячные изменения по каждому каналу
- [ ] Выявить каналы с отрицательным трендом
- [ ] Рассчитать размер снижения (в рублях и %)

### Фаза 4. Анализ по товарам
- [ ] Сгруппировать продажи товаров по месяцам
- [ ] Рассчитать динамику по каждому товару
- [ ] Выявить товары с отрицательным трендом
- [ ] Определить, в каких каналах падают конкретные товары

### Фаза 5. Формирование отчёта
- [ ] Структурировать выводы по каналам (снижение ↑, рост ↓, стабильны =)
- [ ] Структурировать выводы по товарам
- [ ] Сформировать текстовый отчёт с конкретными цифрами
- [ ] Добавить рекомендации

## Критерий завершения
Текстовый отчёт в файле `report.md` с:
- Сводкой по данным (период, количество заказов, каналы)
- Анализом по каналам (где падение, на сколько)
- Анализом по товарам (что падает, на сколько)
- Выводами и рекомендациями

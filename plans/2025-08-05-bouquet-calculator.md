## Кратко о задаче

Создать калькулятор для расчёта стоимости букетов на дашборде Бархат.

**Логика:**
- Цены уже с наценкой (не считать дополнительно)
- Учёт объёмных скидок (клубника, шоколад, посыпки)
- Упаковка = 8% от суммы ИЛИ фиксированная
- Итог округляется до 90 ₽
- Сохранение рецептов букетов

### Формула расчёта

```javascript
function calculateBouquet(items) {
  // items = [{ name, category, quantity }]

  let total = 0

  // 1. Суммируем всё кроме упаковки
  items.forEach(item => {
    if (item.category === 'flowers' || item.category === 'dried') {
      total += PRICE_LIST[item.category][item.name] * item.quantity
    }
    else if (['strawberry', 'chocolate', 'sprinkles'].includes(item.category)) {
      const tiers = PRICE_LIST[item.category].tiers
      const grams = item.quantity
      // Находим нужный tier и считаем цену
      const tier = tiers.find(t => grams <= t.max)
      total += tier.price * grams
    }
    else if (item.category === 'banana') {
      total += PRICE_LIST.banana.price * item.quantity
    }
  })

  // 2. Добавляем упаковку
  const packagingItems = items.filter(i => i.category === 'packaging')
  packagingItems.forEach(item => {
    if (item.name === 'Упаковка (8%)') {
      total += total * 0.08
    } else if (item.name === 'Упаковка + фирм. лента') {
      total += total * 0.08 + 34
    } else {
      total += PRICE_LIST.packaging[item.name]
    }
  })

  // 3. Округление по формуле Excel: ОКРУГЛВВЕРХ(цена;-2)-10
  // Округляем ВВЕРХ до 100, затем вычитаем 10
  return Math.ceil(total / 100) * 100 - 10
}
```

## Что критично не забыть (проверено кровью в этом модуле)

- **Заголовки ответа проверять на живом ответе** (`curl -D -`), а не в коде вьюхи:
  глобальный `after_request` молча выигрывает у вьюхи.
- **Кнопки на тёмном фоне.** Панель массовых действий залита `--bx-wine`; `bx-btn--ghost`
  красит текст в тот же цвет, и кнопка становится невидимой. Для тёмных поверхностей —
  `bx-btn--ghost-light`; в CSS стоит предохранитель, но проверять глазами всё равно надо.
- **Поля, которые читает фронт, сверять с реальным ответом сервера** в конце каждой фазы.
- **Диалоги только `window.BarhatUI`** — нативные `confirm`/`prompt` в iframe Пульса
  молча игнорируются.
- **Экранирование через `escapeHtml`** модуля: трюк `div.textContent` не экранирует кавычку.
- **Время через `window.BarhatTime`**: в базе UTC, показываем по поясу устройства,
  `due_date` — календарная дата, не конвертируется. В тестах считать даты локально, а не
  через `toISOString()`: вечером в UTC+7 это разные сутки.
- **Все правила CSS скоупить под `.iv2`.**
- **Глобальные обработчики `document`** обязаны проверять `pageIsActive()`.
- **История и вложенные соединения — только после `commit`** своего соединения.
- **Миграции схемы** — `ADD COLUMN` под `BEGIN IMMEDIATE`, никакого пересоздания таблиц.
- **Перерисовка формы по `change`** пересоздаёт кнопки между `mousedown` и `click` —
  и кнопка «Сохранить» перестаёт срабатывать. Правьте точечно.
- **Локальный прогон читает боевой `.env`** (`load_dotenv` при импорте) и уходит в боевые
  внешние API. Если прогон трогает ПланФакт, Модульбанк, RetailCRM или МойСклад —
  блокировать сокеты прямо в скрипте:

```python
import socket
class NoNetwork(socket.socket):
    def connect(self, *a, **k): raise OSError("сеть отключена намеренно")
    def connect_ex(self, *a, **k): raise OSError("сеть отключена намеренно")
socket.socket = NoNetwork      # ДО импорта приложения
```

## Как работать

Схема `Goal → Context → Constraints → Done when`. Фазы по одной: реализация → статическая
проверка (у каждой кнопки есть обработчик, каждый `$('#id')` существует, каждое `data-*`
обработано) → прогон на реальном бэкенде через Flask `test_client` на временной базе →
отметки в плане → коммит → сводка владельцу → ждать подтверждения на следующую фазу.
